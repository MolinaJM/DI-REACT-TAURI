# Desarrollo de Interfaces 2.0

React + Tauri — Segundo de Desarrollo de Aplicaciones Multiplataforma

## Sesiones del curso (material estático)

- **SESION 0** - [Fundamentos de Arquitectura y Configuración del Entorno](sesion00.md): Node.js, NPM, Vite, React, Tailwind CSS, Rust y Tauri.
- **SESION 1** - [Instalación del Entorno de Desarrollo](sesion01.md): Node.js, React y Tauri paso a paso en Linux y WSL.
- **SESION 1-S** - [Scaffolding de un Proyecto Tauri con React y Rust](sesion01_scaffolding.md): Estructura de archivos, Cargo.toml, tauri.conf.json, invoke e IPC.
- **SESION 2** - [Introducción a TypeScript desde cero (Parte 1)](sesion02.md): Sintaxis, tipos primitivos, uniones, narrowing, funciones, type guards y operadores (ruta obligatoria para React + Tauri).
- **SESION 3** - [Introducción a TypeScript desde cero (Parte 2)](sesion03.md): Generics, utility types, módulos y asincronía tipada (clave para `invoke()`); optativos: OOP, enums y DOM.
- **SESION 4** - [Anatomía de Componentes y Funciones con TypeScript](sesion04.md): Fundamentos de componentes funcionales y composición.
- **SESION 5** - [Gestión de Estado Básico y Tipado de Formularios](sesion05.md): localStorage, state management, reducer pattern.
- **SESION 6** - [Creación de Componentes Personalizados](sesion06.md): Patrones avanzados de componentes reutilizables.
- **SESION 7** - [El Puente de Comunicación (Tauri IPC) y Sistema de Archivos](sesion07.md): Tauri commands, IPC entre frontend y backend Rust.
- **SESION 8** - [Persistencia de Estado Global y Enrutado](sesion08.md): Persistencia entre sesiones y router SPA.
- **SESION 9** - [Formulario CRUD para Bases de Datos](sesion09.md): Conexión a MySQL mediante API REST.
- **SESION 10** - [Estilización Avanzada con Tailwind CSS](sesion10.md): Diseño de interfaces con utilidades CSS.
- **SESION 11** - [Creación de Informes en PDF con React](sesion11.md): Generación de PDFs con @react-pdf/renderer.
- **SESION 12** - [Prueba Automatizada con Jest/Testing Library](sesion12.md): Estrategias de testing para componentes React.
- **SESION 13** - [Distribución Multiplataforma con Tauri](sesion13.md): Instaladores nativos, bundle, GitHub Actions y actualizaciones.
